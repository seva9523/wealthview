# Authors and project stewardship

WealthView was created and is maintained by
[Sevinj Ahmadova](https://github.com/seva9523). The project explores read-only Stellar treasury
aggregation, portfolio visibility, developer APIs, and agent-ready treasury intelligence without
wallet custody or transaction permissions.

Professional and research background is available on
[LinkedIn](https://www.linkedin.com/in/sevinj-ahmadova-imc-240738131/).

## Evidence and contribution principles

- Material code and documentation contributions retain their Git attribution.
- Public claims about integrations, adoption, users, or outcomes should match independently
  verifiable repository and deployment evidence.
- AI-assisted changes require human review and the repository's available checks before merge.
- Security reports should use the repository's security process rather than public issue threads.
